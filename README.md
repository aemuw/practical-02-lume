# Практична робота №2 — LUME

## Тема

Створення семантичної HTML-структури вебсторінки на основі макета, розробленого у Figma.

## Опис проєкту

**LUME** — концептуальний вебсайт магазину сучасних предметів для дому.  
За основу взято дизайн домашньої сторінки з попередньої практичної роботи у Figma.

У цій практичній роботі реалізовано HTML-структуру сторінки без використання CSS та JavaScript.

## Структура проєкту

```text
practical-02-lume/
├── index.html
└── README.md
```

Додаткові папки та зображення не використовуються.

## Реалізовано

- семантичну структуру HTML-документа;
- `header`, `nav`, `main`, `section`, `article`, `footer`;
- заголовки різних рівнів `h1`, `h2`, `h3`;
- текстовий контент відповідно до макета LUME;
- навігаційні посилання;
- список товарів;
- форму пошуку;
- кнопки та посилання;
- доступний skip-link для переходу до основного вмісту;
- атрибути `lang`, `title`, `meta description` та `viewport`;
- логічну структуру сторінки без прив'язки до візуального оформлення.

## Використані технології

- HTML5
- Git
- GitHub
- Visual Studio Code

CSS та JavaScript у межах цієї практичної роботи не використовуються.

## Запуск

Відкрити файл `index.html` у браузері.
